# 10-Minute Demo and Presentation Plan

| Time | Presenter | Demonstration |
|---|---|---|
| 0:00–1:00 | Project Manager | Problem, target users and project objective |
| 1:00–2:00 | Documentation Lead | Requirements and scope: five core capabilities |
| 2:00–4:00 | Lead Developer | Register a customer and vehicle |
| 4:00–6:00 | Lead Developer | Create job card; update status |
| 6:00–7:00 | Tester | Show mock SMS notification and automated test command/results |
| 7:00–8:00 | Lead Developer | Record a payment entry and show database persistence |
| 8:00–9:00 | Documentation Lead | UML, architecture, risks and limitations |
| 9:00–10:00 | All | Lessons learned, next steps and questions |

**Before the demo:** install dependencies, run tests, start the app, use fictional sample data, verify mock SMS, close unrelated applications, and prepare a backup recording/screenshots.
